### 🏗 [Mu3Library For Unity](https://github.com/doqltl179/Mu3Library_ForUnity)

<div align="left">

![Unity](https://img.shields.io/badge/Unity-6000.0%2B-000000?style=flat-square&logo=unity&logoColor=white)
![C#](https://img.shields.io/badge/C%23-512BD4?style=flat-square&logo=csharp&logoColor=white)
![HLSL](https://img.shields.io/badge/HLSL-DBBC04?style=flat-square)
![MIT License](https://img.shields.io/badge/License-MIT-green?style=flat-square)

</div>

> **Modular architecture package set for Unity 6**
>
> Three layered Unity packages built on a custom DI container and an MVP UI pattern. Optional integrations are gated behind define symbols, so a project that does not install UniTask, Addressables, Localization, the Input System, or Mobile Notifications compiles without them and pays nothing for them.

| Package | Version | Depends on |
|---|---|---|
| `Mu3Library_Base` | 0.26.0 | — |
| `Mu3Library_URP` | 0.3.0 | Base |
| `Mu3Library_Game_WatermelonGame` | 0.6.0 | Base, URP |

**Key Features:**
- 💉 **DI container** — Singleton, Transient, and Scoped lifetimes, with field and property injection across cores
- 🎨 **MVP UI** — View, Presenter, and Model separation, with awaitable open and close
- 🏗 **Core modules** — deterministic execution order over `IInitializable`, `IUpdatable`, and `IDisposable`
- 🎵 **Audio** — BGM, SFX, and environment channels with mixer-group routing, BGM ducking, awaitable fades, and persisted volumes
- 🌐 **WebRequest** — GET, POST, PUT, PATCH, and DELETE with retry backoff, in-flight cancellation, and download progress
- 🎮 **Input & notifications** — interactive rebinding with binding-override persistence, and mobile notification scheduling on Android and iOS
- 🖼 **URP screen effects** — grayscale, shake, gaussian blur, and depth outline, plus camera-stack helpers
- 🍉 **Watermelon Game package** — an eleven-item 2D merge board with a configurable `BoardConfig` and a playable sample scene
- 🧰 **Editor tooling** — DI resolution validator, runtime diagnostics, and Addressables/Localization exporters
- ✅ **Edit-mode test suites** and documentation in English, Korean, and Japanese
